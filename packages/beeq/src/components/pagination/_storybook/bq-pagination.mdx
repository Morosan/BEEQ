  <div className="bq-doc__container">
    <Title>Pagination</Title>

    The Pagination component helps users navigate through content divided into multiple pages.
    It is commonly used with tables, search results, and long lists.

    <Subtitle>Usage</Subtitle>

    Use pagination when content is split into pages and users need direct access to nearby pages,
    the first page, and the last page.
    Hide the arrow controls when the surrounding layout already provides previous and next navigation.

    <Subtitle>👍 When to use</Subtitle>

    - Use pagination for large data sets where showing all content at once would be overwhelming.
    - Use it when users need to understand their current position within a finite result set.
    - Avoid it for short lists where all items can be shown comfortably.
