Spinners reassure people that the system is still working during loading, submitting, syncing, or processing states. Use them when the task is active but the exact progress cannot be measured.

<Note>
  Show a spinner only when the wait is noticeable, typically longer than one second. If progress can be measured, prefer a [progress bar](/components/progress) instead.
</Note>

## When to use

<CardGroup cols={2}>
  <Card>
    <span className="flex items-center mr-2 text-lg font-medium" role="heading">
      <Icon className="mr-2" icon="thumbs-up" iconType="solid" size={20} color="var(--bq-stroke--success)" />
      Use spinners when
    </span>
    - The system is actively loading, submitting, or processing
    - The wait is long enough that users may wonder whether anything is happening
    - The duration is unknown or cannot be expressed reliably as a percentage
    - A compact loading indicator is needed inside a card, button, panel, or page section
  </Card>
  <Card>
    <span className="flex items-center mr-2 text-lg font-medium" role="heading">
      <Icon className="mr-2" icon="thumbs-down" iconType="solid" size={20} color="var(--bq-stroke--danger)" />
      Do not use spinners when
    </span>
    - The task finishes almost instantly and no feedback is needed
    - Progress can be measured precisely and should be communicated with a progress bar
    - Several different areas on the same page would spin at once and compete for attention
    - The animation would be decorative rather than meaningful feedback
  </Card>
</CardGroup>

## Spinner patterns

<CardGroup cols={3}>
  <Card title="No label">
    The most compact option for small or well-scoped loading states where surrounding UI already explains the context.
  </Card>
  <Card title="Label below">
    A strong default for standalone loading states because the label adds context without widening the layout.
  </Card>
  <Card title="Inline label">
    Use `text-position="right"` or `text-position="left"` when the spinner needs to fit into a horizontal layout.
  </Card>
  <Card title="Label above">
    Useful when vertical rhythm or the surrounding composition calls for the message to appear first.
  </Card>
  <Card title="Size variants">
    Match the spinner size to the container: `small` for tight spaces, `medium` for most cases, `large` for prominent loading areas.
  </Card>
  <Card title="Custom icon">
    Override the default loader using the `icon` slot when you need a different branded or contextual spinner icon.
  </Card>
</CardGroup>

The spinner combines a rotating circular indicator with an optional label. Keep the message short and specific so people understand what is happening without needing to read a sentence.

| Part | Element | Description |
|---|---|---|
| **1** | Spinner icon | The animated circular loader that signals ongoing activity |
| **2** | Indicator arc | The emphasized segment that creates the motion cue and sense of rotation |
| **3** | Label | Optional text that clarifies what is loading, submitting, or processing |

## Accessibility

- **Provide context** — visible text such as "Loading results..." helps everyone, especially when the spinner appears away from the triggering action.
- **Treat the label as meaningful content** — when you render text with `text-position`, use concise task-oriented wording like "Syncing changes..." instead of generic filler.
- **Be careful with custom icons** — replacing the default loader with the `icon` slot changes the built-in loading indicator, so test that the loading state is still understandable in context for assistive technologies.
- **Avoid misleading motion changes** — setting `animation={false}` can make an active process look stalled, so only stop animation if another clear status treatment explains that work is still ongoing.
- **Limit simultaneous announcements** — too many independent loading indicators can create noise for screen reader users and make it harder to understand which region is updating.

## API reference

### Properties

| Property | Attribute | Description | Type | Default |
|---|---|---|---|---|
| `animation` | `animation` | If `false`, the animation on the icon element will be stopped | `boolean` | `true` |
| `size` | `size` | Defines the size of the icon element displayed | `"small"` \| `"medium"` \| `"large"` | `"medium"` |
| `textPosition` | `text-position` | Defines the position of the label text | `"none"` \| `"left"` \| `"right"` \| `"above"` \| `"below"` | `"none"` |

### Slots

| Slot | Description |
|---|---|
| *(default)* | The label or loading message content |
| `icon` | A custom icon that replaces the default spinner loader |

### Shadow parts

| Part | Description |
|---|---|
| `base` | The wrapper container used under the hood |
| `icon` | The default `<svg>` icon element used to spin or animate |
| `custom-icon` | The `<span>` element that wraps slotted custom icon content |
| `text` | The `<span>` element that renders the label text |
